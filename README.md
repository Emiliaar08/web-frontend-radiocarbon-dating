# Радиоуглеродное датирование — ЛР-5

## Страницы, поля и кнопки

### Плитка органических останков — `/remains`

Главная страница `/` перенаправляет на плитку. Карточка показывает фото, название образца, содержание C-14 в pMC, время анализа в днях и число лайков. Нажатие на карточку открывает соответствующий образец в ленте.

Поле «Содержание C-14, pMC» — числовой ползунок от 0 до 200 с шагом 0,1. Подпись под ним меняется сразу при перемещении. Кнопка с лупой «Найти» применяет нижнюю границу содержания C-14: остаются образцы со значением не меньше выбранного. «Сбросить» возвращает все образцы. При отсутствии совпадений выводится сообщение.

### Лента радиоуглеродного датирования — `/remains/feed/:remainId`

В фоне автоматически воспроизводится зацикленное видео без звука. Поверх видео показаны фото, название и описание образца. Справа находятся содержание C-14, время анализа, число лайков и иконка «Следующий образец».

«Развернуть» показывает полное описание, «Свернуть» возвращает сокращённое. Иконка со стрелкой переключает на следующий образец из отфильтрованной коллекции, а с последнего — на первый. Следующий объект определяется по существующим идентификаторам, поэтому пропуски в ID не мешают переходу. Прямой адрес открывает образец и после обновления страницы. `/remains/feed` открывает первый подходящий образец, а при пустом результате фильтра — первый образец всей коллекции. При прямом открытии образца вне фильтра переходы идут по всей коллекции.

Лайки в гостевом интерфейсе показывают число из mock, изменить его нельзя.

### Образец не найден — неизвестный адрес или ID

Страница с кодом 404 и кнопкой «К образцам», которая возвращает в плитку. Это служебная страница, два основных экрана — плитка и лента, как требует раздел 7.3 методических указаний.

### Нижняя панель навигации

На всех страницах четыре пункта: «Лента», «Добавление», «Плитка», «Вход». Доступны только «Лента» и «Плитка». Добавление и вход отключены по заданию ЛР-5. Активный пункт подчёркнут; переходы выполняются React Router без перезагрузки документа.

## Mock и медиа по умолчанию

Все поля карточек берутся из `src/modules/remains_mock.ts`. Запросов к API бэкенда нет. Содержание C-14 приведено в pMC — процентах относительно активности современного углерода; это характеристика конкретного образца, а не постоянная величина для типа останков. Демонстрационные значения перенесены из данных предыдущих лабораторных.

Уголь, кости и ракушки используют адреса медиа из MinIO `http://localhost:9000/remains`. Это загрузка изображений и видео, а не получение карточек с бэкенда. Если MinIO недоступен, приложение подставляет локальные файлы. Для демонстрации пустых полей у дерева `image_url` и `video_url` намеренно пустые.

Фото `public/remains/wood.jpg` и видео `public/remains/wood-video.mp4` хранятся в проекте. `RemainsImage` и `RemainsVideo` используют их при пустом поле или ошибке загрузки. Видео воспроизводится с `autoPlay`, `muted`, `loop`, `playsInline`. Шрифт Inter также локальный; лицензия находится в `public/fonts/OFL.txt`.

## Компоненты и хуки

`App` хранит применённую границу C-14 в `useState` и передаёт отфильтрованные объекты страницам через props. `RemainsFilter` получает `carbonMinimum` и `onApply`, хранит текущее значение ползунка в собственном `useState` и вызывает `onApply` при отправке формы. `RemainsCard` получает объект `remain` через props. `RemainInFeed` хранит состояние развёрнутого описания в `useState`; при смене образца оно сбрасывается благодаря `key`.

`useEffect` в `App` обновляет заголовок вкладки при смене маршрута. `useParams` читает ID образца, `useLocation` используется для заголовка вкладки и активного пункта меню. React-Bootstrap используется для карточек, формы, ползунка, кнопок, изображений и нижнего Navbar. Redux и собственный Context не используются.
